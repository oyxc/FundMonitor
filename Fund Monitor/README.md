# FundMonitor - 基金估值查看应用

一款使用 Objective-C 开发的 iOS 基金估值实时查看应用。

## 功能特性

### 1. 自选基金模块
- 展示自选基金列表，实时显示估值和涨跌幅
- 点击基金可查看详细信息
- 支持添加新基金到自选列表
- 支持左滑删除自选基金
- 下拉刷新更新估值数据

### 2. 热门基金模块
- 展示热门基金列表
- 实时显示估值和涨跌幅
- 点击可查看基金详情
- 支持从热门基金添加到自选

### 3. 分组管理功能
- 自选模块顶部可切换分组
- 支持创建自定义分组
- 支持编辑和删除分组
- 默认分组不可删除
- 删除分组时，基金自动移到默认分组

### 4. 基金详情页面
- 显示基金完整信息（名称、代码、类型、经理、公司等）
- 显示当前估值和涨跌幅
- 支持加入/移除自选
- 自动刷新最新估值

### 5. 添加基金功能
- 搜索基金（支持代码或名称）
- 选择分组添加到自选
- 显示已加入自选的标识

## 技术实现

### 数据模型
- **FMFund**: 基金数据模型，包含基金代码、名称、估值、涨跌幅等信息
- **FMGroup**: 分组数据模型，支持自定义分组管理

### 数据管理
- **FMDataManager**: 单例模式，负责本地数据持久化
  - 使用 NSUserDefaults 存储数据
  - 使用 NSCoding 协议序列化对象
  - 支持基金和分组的增删改查

### 网络请求
- **FMNetworkManager**: 单例模式，负责网络数据获取
  - 搜索基金
  - 获取基金实时估值
  - 批量获取多个基金估值
  - 获取热门基金列表
  - 获取基金详细信息

### UI实现
- 使用纯代码布局（Auto Layout）
- UITableView 展示列表
- UISegmentedControl 切换分组
- UISearchBar 搜索基金
- 支持下拉刷新
- 支持左滑删除

### 数据持久化
- 自选基金列表持久化
- 分组信息持久化
- 热门基金缓存

## 使用说明

### 添加基金到自选
1. 点击自选页面右上角的 "+" 按钮
2. 在搜索框输入基金代码或名称
3. 点击搜索结果中的基金
4. 选择要添加到的分组
5. 确认添加

### 管理分组
1. 点击自选页面右上角的 "分组" 按钮
2. 点击右上角 "+" 创建新分组
3. 点击分组可编辑名称
4. 左滑分组可删除（默认分组除外）

### 查看基金详情
1. 在自选或热门列表中点击任意基金
2. 查看基金详细信息
3. 可以在详情页加入或移除自选

### 刷新数据
- 在自选或热门页面下拉刷新
- 应用会自动获取最新估值数据

## 数据来源

**已接入真实API**，实时获取基金数据：

### 1. 基金搜索
- **API**: 东方财富基金搜索接口
- **地址**: `https://fundsuggest.eastmoney.com/FundSearch/api/FundSearchAPI.ashx`
- **功能**: 根据基金代码或名称搜索基金

### 2. 实时估值
- **API**: 天天基金网实时估值接口
- **地址**: `http://fundgz.1234567.com.cn/js/{fundCode}.js`
- **功能**: 获取基金实时估值、涨跌幅等数据
- **更新频率**: 交易日 9:30-15:00 每分钟更新

### 3. 热门基金
- **实现**: 预设热门基金代码，批量获取实时估值
- **基金列表**: 包含股票型、混合型、指数型等热门基金

详细API文档请查看 [API_GUIDE.md](API_GUIDE.md)

5. **数据更新**: 交易日 9:30-15:00 数据每分钟更新，非交易时间显示上一交易日数据
